Practice Problems: Multiple Integrals (Ch 14.1 - 14.5)

Chapter 14.1: Double Integrals over Rectangles

  1. Problem 34: Evaluate the double integral:

    ∫∫_R (5 - cos 3x) dA

    over the rectangle R = {(x, y) : 0 ≤ x ≤ π/6, 0 ≤ y ≤ 3}.
    Show Solution

    Step 1: Set up the iterated integral.

    ∫ [0 to 3] ∫ [0 to π/6] (5 - cos(3x)) dx dy

    Step 2: Evaluate the inner integral with respect to x.

    The antiderivative of 5 - cos(3x) with respect to x is 5x - (1/3)sin(3x).

    Evaluate from 0 to π/6:

    Upper bound: 5(π/6) - (1/3)sin(3 * π/6) = 5π/6 - (1/3)sin(π/2) = 5π/6 - 1/3

    Lower bound: 5(0) - (1/3)sin(0) = 0 - 0 = 0

    Inner result: 5π/6 - 1/3

    Step 3: Evaluate the outer integral with respect to y.

    Since the inner result is a constant, we integrate a constant with respect to y:

    ∫ [0 to 3] (5π/6 - 1/3) dy

    = [ (5π/6 - 1/3)y ] from 0 to 3

    = 3 * (5π/6 - 1/3) = 5π/2 - 1

    Answer: 5π/2 - 1

  2. Problem 35: Evaluate the double integral:

    ∫∫_R f(x, y) dA

    over the rectangle R = [0, 1] × [-2, 5], where f(x, y) = 1 / (x² + 1).
    Show Solution

    Step 1: Set up the integral and use separability.

    Since the bounds are constants and the function only depends on x, we can separate the integrals:

    ∫ [-2 to 5] ∫ [0 to 1] ( 1 / (x² + 1) ) dx dy

    = ( ∫ [-2 to 5] 1 dy ) * ( ∫ [0 to 1] 1 / (x² + 1) dx )

    Step 2: Evaluate the y-integral.

    ∫ [-2 to 5] 1 dy = [y] from -2 to 5 = 5 - (-2) = 7

    Step 3: Evaluate the x-integral.

    The antiderivative of 1 / (x² + 1) is arctan(x) (or tan⁻¹(x)).

    ∫ [0 to 1] 1 / (x² + 1) dx = [arctan(x)] from 0 to 1

    = arctan(1) - arctan(0) = π/4 - 0 = π/4

    Step 4: Multiply the results.

    7 * (π/4) = 7π/4

    Answer: 7π/4

  3. Problem 36: Evaluate the double integral:

    ∫ [0 to π] ∫ [0 to π] x²y sin(x³y) dx dy
    Show Solution

    Step 1: Evaluate the inner integral with respect to x.

    ∫ [0 to π] x²y sin(x³y) dx

    Use u-substitution: Let u = x³y. Then the derivative with respect to x is du = 3x²y dx.

    This means x²y dx = du / 3.

    Change the bounds for u: When x = 0, u = (0³)y = 0. When x = π, u = π³y.

    The integral becomes: ∫ [0 to π³y] (1/3)sin(u) du

    = [-(1/3)cos(u)] from 0 to π³y

    = -(1/3)cos(π³y) - (-(1/3)cos(0))

    Since cos(0) = 1, this simplifies to: 1/3 - (1/3)cos(π³y)

    Step 2: Evaluate the outer integral with respect to y.

    ∫ [0 to π] (1/3 - (1/3)cos(π³y)) dy

    Integrate term by term:

    The integral of 1/3 is (1/3)y.

    The integral of -(1/3)cos(π³y) requires a reverse chain rule (divide by the constant multiplier of y, which is π³):
    -(1/3) * (1/π³)sin(π³y) = -sin(π³y) / (3π³)

    Evaluate from 0 to π:

    Upper bound: (1/3)π - sin(π³ * π) / (3π³) = π/3 - sin(π⁴) / (3π³)

    Lower bound: (1/3)0 - sin(0) / (3π³) = 0 - 0 = 0

    Answer: π/3 - sin(π⁴)/(3π³)

  4. Problem 37: Evaluate the iterated integral:

    ∫ [0 to 1] ∫ [0 to 1] (xy) / √(x² + y² + 1) dx dy
    Show Solution

    Step 1: Evaluate the inner integral with respect to x.

    ∫ [0 to 1] xy(x² + y² + 1)^(-1/2) dx

    Use u-substitution: Let u = x² + y² + 1. Treating y as a constant, du = 2x dx, so x dx = du / 2.

    Change bounds: When x = 0, u = y² + 1. When x = 1, u = y² + 2.

    The integral becomes: ∫ [y²+1 to y²+2] (y/2) u^(-1/2) du

    The antiderivative of u^(-1/2) is 2u^(1/2).

    = [ (y/2) * 2u^(1/2) ] = [ y√u ] from y²+1 to y²+2

    = y√(y² + 2) - y√(y² + 1)

    Step 2: Evaluate the outer integral with respect to y.

    ∫ [0 to 1] ( y√(y² + 2) - y√(y² + 1) ) dy

    We can evaluate this by splitting it into two separate u-substitutions.

    For the first part, let w = y² + 2, so dw = 2y dy.
    The integral of y√(y² + 2) becomes (1/2)∫ w^(1/2) dw = (1/2)(2/3)w^(3/2) = (1/3)(y² + 2)^(3/2).

    For the second part, let v = y² + 1, so dv = 2y dy.
    The integral of y√(y² + 1) becomes (1/3)(y² + 1)^(3/2).

    Combine and evaluate from 0 to 1:

    [ (1/3)(y² + 2)^(3/2) - (1/3)(y² + 1)^(3/2) ] from 0 to 1

    Upper bound (y=1): (1/3)(3)^(3/2) - (1/3)(2)^(3/2) = (1/3)(3√3 - 2√2) = √3 - (2√2)/3

    Lower bound (y=0): (1/3)(2)^(3/2) - (1/3)(1)^(3/2) = (1/3)(2√2 - 1) = (2√2)/3 - 1/3

    Subtract lower from upper:

    (√3 - 2√2/3) - (2√2/3 - 1/3) = √3 - 4√2/3 + 1/3

    Answer: √3 - 4√2/3 + 1/3

Chapter 14.2: Double Integrals over General Regions

  1. Problem 38: Evaluate the double integral:

    ∫ [0 to 1] ∫ [y to 1] eˆ(-x²) dx dy
    Show Solution

    Step 1: Recognize the need to reverse the order of integration.

    The inner integral is ∫ eˆ(-x²) dx, which has no elementary antiderivative. We must change the order of integration to dy dx.

    Step 2: Sketch the region of integration.

    From the given bounds, the region R is defined by:
    Inner bounds: x = y to x = 1 (Right of the line y=x, bounded by the vertical line x=1)
    Outer bounds: y = 0 to y = 1

    This forms a triangle with vertices at (0,0), (1,0), and (1,1).

    Step 3: Set up the new bounds for dy dx.

    To integrate with respect to y first (vertical strips), we look at the y-values from bottom to top:
    Bottom curve: y = 0
    Top curve: y = x

    The x-values for this entire triangle go from x = 0 to x = 1.

    The new integral is: ∫ [0 to 1] ∫ [0 to x] eˆ(-x²) dy dx

    Step 4: Evaluate the new integral.

    Inner integral (dy): ∫ [0 to x] eˆ(-x²) dy = [ y * eˆ(-x²) ] from 0 to x = x * eˆ(-x²)

    Outer integral (dx): ∫ [0 to 1] x * eˆ(-x²) dx

    Use u-substitution: Let u = -x², then du = -2x dx, so x dx = -1/2 du.
    Change bounds: When x=0, u=0. When x=1, u=-1.

    = ∫ [0 to -1] (-1/2) eˆu du = [-1/2 eˆu] from 0 to -1

    = -1/2(eˆ(-1) - eˆ0) = -1/2(1/e - 1) = 1/2(1 - 1/e)

    Answer: (1/2)(1 - 1/e)

  2. Problem 39: Using a double integral to find the area enclosed by the equations:

    y = -x, -x + y = 2, and y = 2.
    Show Solution

    Step 1: Identify the bounding curves and intersection points.

    Curve 1: y = -x &implies; x = -y
    Curve 2: -x + y = 2 &implies; x = y - 2
    Curve 3: y = 2 (Horizontal line)

    Find where Curve 1 and Curve 2 intersect:
    -y = y - 2 &implies; 2y = 2 &implies; y = 1. (Point: (-1, 1))

    The region is bounded below by y = 1 and above by y = 2.

    Step 2: Set up the integral.

    Since the left and right boundaries are cleanly defined by functions of y, it's easiest to integrate with respect to x first (horizontal strips, dx dy).
    Left curve (smaller x): x = -y
    Right curve (larger x): x = y - 2

    (Check at y=2: left x=-2, right x=0. So x = -y is indeed on the left).

    Area = ∫∫_R 1 dA = ∫ [1 to 2] ∫ [-y to y-2] 1 dx dy

    Step 3: Evaluate.

    Inner integral: ∫ [-y to y-2] 1 dx = [x] from -y to y-2 = (y - 2) - (-y) = 2y - 2

    Outer integral: ∫ [1 to 2] (2y - 2) dy = [y² - 2y] from 1 to 2

    Upper bound (y=2): (2)² - 2(2) = 4 - 4 = 0

    Lower bound (y=1): (1)² - 2(1) = 1 - 2 = -1

    0 - (-1) = 1

    Answer: The area is 1.

  3. Problem 40: Use a double integral to find the volume of the region bounded above by the plane x + y + z = 3 and below by the rectangle with equations x = -2, y = 1, x = 0, and y = 5.
    Show Solution

    Step 1: Set up the volume integral.

    Volume = ∫∫_R f(x,y) dA

    The top surface is z = 3 - x - y. The region R is a rectangle with -2 ≤ x ≤ 0 and 1 ≤ y ≤ 5.

    V = ∫ [-2 to 0] ∫ [1 to 5] (3 - x - y) dy dx

    Step 2: Evaluate the inner integral (dy).

    ∫ [1 to 5] (3 - x - y) dy = [ 3y - xy - y²/2 ] from 1 to 5

    Upper bound (y=5): 15 - 5x - 25/2 = 5/2 - 5x

    Lower bound (y=1): 3 - x - 1/2 = 5/2 - x

    Subtract lower from upper: (5/2 - 5x) - (5/2 - x) = -4x

    Step 3: Evaluate the outer integral (dx).

    ∫ [-2 to 0] (-4x) dx = [ -2x² ] from -2 to 0

    = 0 - (-2(-2)²) = 0 - (-8) = 8

    Answer: The volume is 8.

  4. Problem 41: Use a double integral to find the area of the region R enclosed by:

    y = -x + 1, y = eˆx, y = 0, and x = 2
    Show Solution

    Step 1: Sketch and understand the region.

    The curve y = eˆx and the line y = -x + 1 intersect precisely at (0, 1) because eˆ0 = 1 and -0 + 1 = 1.

    The line y = -x + 1 hits the x-axis (y = 0) at x = 1.

    The region is bounded on the right by the vertical line x = 2.

    Therefore, the region spans from x = 0 to x = 2, but the "bottom" curve changes halfway:
    From x=0 to x=1, the bottom curve is the line y = -x + 1.
    From x=1 to x=2, the bottom curve is the x-axis y = 0.

    The top curve is always y = eˆx.

    Step 2: Set up the integral(s).

    We split the area into two integrals:

    Area = ∫ [0 to 1] (Top - Bottom) dx + ∫ [1 to 2] (Top - Bottom) dx

    Area = ∫ [0 to 1] (eˆx - (-x + 1)) dx + ∫ [1 to 2] (eˆx - 0) dx

    Step 3: Evaluate the integrals.

    First integral: ∫ [0 to 1] (eˆx + x - 1) dx = [eˆx + x²/2 - x] from 0 to 1

    = (eˆ1 + 1/2 - 1) - (eˆ0 + 0 - 0) = e - 1/2 - 1 = e - 3/2

    Second integral: ∫ [1 to 2] eˆx dx = [eˆx] from 1 to 2 = e² - e

    Total Area = (e - 3/2) + (e² - e) = e² - 3/2

    Answer: e² - 3/2

  5. Problem 42: Find the volume of the solid bounded by f(x, y) = 2xy and bounded region R in the xy-plane, where R is the region in the first quadrant enclosed between y² = 4x and the line y = ½x.
    Show Solution

    Step 1: Find the intersection points to determine bounds.

    Substitute x = 2y (from the line equation) into the parabola equation:

    y² = 4(2y) &implies; y² = 8y &implies; y² - 8y = 0 &implies; y(y - 8) = 0

    The intersections are at y = 0 and y = 8.

    Step 2: Set up the integral.

    We'll integrate with respect to x first (horizontal strips, dx dy).
    Left boundary (smaller x): y² = 4x &implies; x = y²/4
    Right boundary (larger x): y = ½x &implies; x = 2y

    V = ∫ [0 to 8] ∫ [y²/4 to 2y] (2xy) dx dy

    Step 3: Evaluate inner integral (dx).

    ∫ [y²/4 to 2y] 2xy dx = [ x²y ] from y²/4 to 2y

    Upper: (2y)²y = 4y² * y = 4y³

    Lower: (y²/4)²y = (yˆ4 / 16)y = yˆ5 / 16

    Result: 4y³ - yˆ5 / 16

    Step 4: Evaluate outer integral (dy).

    ∫ [0 to 8] (4y³ - yˆ5 / 16) dy = [ yˆ4 - yˆ6 / 96 ] from 0 to 8

    Evaluate at y=8:

    8ˆ4 - 8ˆ6 / 96 = 4096 - 262144 / 96

    Simplify the fraction: 262144 / 96 = 8192 / 3

    4096 - 8192/3 = 12288/3 - 8192/3 = 4096/3

    Answer: The volume is 4096/3.

Chapter 14.5: Triple Integrals

  1. Problem 43: Evaluate the triple integral:

    ∫ [0 to 2] ∫ [-1 to 1] ∫ [0 to 2] yz dx dz dy
    Show Solution

    Step 1: Evaluate the inner integral with respect to x.

    ∫ [0 to 2] yz dx = [xyz] from x=0 to x=2

    = 2yz - 0 = 2yz

    Step 2: Evaluate the middle integral with respect to z.

    ∫ [-1 to 1] 2yz dz = [yz²] from z=-1 to z=1

    = y(1)² - y(-1)² = y - y = 0

    Step 3: Evaluate the outer integral with respect to y.

    ∫ [0 to 2] 0 dy = 0

    Answer: 0

  2. Problem 44: Evaluate the triple integral:

    ∫ [0 to π/4] ∫ [0 to x²] ∫ [0 to 2] x cos(y) dz dy dx
    Show Solution

    Step 1: Evaluate the inner integral with respect to z.

    ∫ [0 to 2] x cos(y) dz = [z * x cos(y)] from z=0 to z=2

    = 2x cos(y)

    Step 2: Evaluate the middle integral with respect to y.

    ∫ [0 to x²] 2x cos(y) dy = [2x sin(y)] from y=0 to y=x²

    = 2x sin(x²) - 2x sin(0) = 2x sin(x²)

    Step 3: Evaluate the outer integral with respect to x.

    ∫ [0 to π/4] 2x sin(x²) dx

    Use u-substitution: Let u = x², then du = 2x dx.
    Change bounds: When x = 0, u = 0. When x = π/4, u = π²/16.

    ∫ [0 to π²/16] sin(u) du = [-cos(u)] from 0 to π²/16

    = -cos(π²/16) - (-cos(0)) = 1 - cos(π²/16)

    Answer: 1 - cos(π²/16)

  3. Problem 45: Evaluate the triple integral:

    ∫∫∫_G xy sin(yz) dV

    where G is the rectangular box defined by the inequalities 0 ≤ x ≤ π, 0 ≤ y ≤ 1, and 0 ≤ z ≤ π/6.
    Show Solution

    Step 1: Set up the integral.

    Integrate with respect to z first to simplify the sine term:
    ∫ [0 to π] ∫ [0 to 1] ∫ [0 to π/6] xy sin(yz) dz dy dx

    Step 2: Evaluate inner integral (dz).

    ∫ [0 to π/6] xy sin(yz) dz

    The antiderivative of sin(yz) with respect to z is (-1/y)cos(yz).

    = [xy * (-1/y)cos(yz)] = [-x cos(yz)] from 0 to π/6

    = -x cos(πy/6) - (-x cos(0)) = x - x cos(πy/6) = x(1 - cos(πy/6))

    Step 3: Evaluate middle integral (dy).

    ∫ [0 to 1] x(1 - cos(πy/6)) dy = x [y - (6/π)sin(πy/6)] from 0 to 1

    = x(1 - (6/π)sin(π/6)) - x(0 - 0)

    Since sin(π/6) = 1/2, this becomes: x(1 - 3/π)

    Step 4: Evaluate outer integral (dx).

    ∫ [0 to π] (1 - 3/π)x dx = (1 - 3/π) [x²/2] from 0 to π

    = (1 - 3/π) * (π²/2) = π²/2 - 3π/2

    Answer: π²/2 - 3π/2

  4. Problem 46: Evaluate the triple integral:

    ∫∫∫_G y dV

    where G is the solid enclosed by the plane z = y, the xy-plane (z = 0), and the parabolic cylinder y = 1 - x².
    Show Solution

    Step 1: Set up the bounds.

    The solid is bounded below by z = 0 and above by z = y.

    In the xy-plane, the base region is bounded by y = 1 - x². Since z ≥ 0 and z = y, we must have y ≥ 0. The intersections of y = 1 - x² and y = 0 are x = -1 and x = 1.

    Integral: ∫ [-1 to 1] ∫ [0 to 1-x²] ∫ [0 to y] y dz dy dx

    Step 2: Evaluate inner integral (dz).

    ∫ [0 to y] y dz = [yz] from 0 to y = y(y) - 0 = y²

    Step 3: Evaluate middle integral (dy).

    ∫ [0 to 1-x²] y² dy = [y³/3] from 0 to 1-x² = (1/3)(1 - x²)³

    Step 4: Evaluate outer integral (dx).

    Expand (1 - x²)³ = 1 - 3x² + 3xˆ4 - xˆ6.

    (1/3) ∫ [-1 to 1] (1 - 3x² + 3xˆ4 - xˆ6) dx

    Since the function is even, we can integrate from 0 to 1 and multiply by 2:

    = (2/3) [x - x³ + (3/5)xˆ5 - (1/7)xˆ7] from 0 to 1

    = (2/3)(1 - 1 + 3/5 - 1/7) = (2/3)(21/35 - 5/35) = (2/3)(16/35) = 32/105

    Answer: 32/105

  5. Problem 47: Evaluate the triple integral:

    ∫∫∫_G xyz dV

    where G is the solid in the first octant bounded by the parabolic cylinder z = 2 - x² and the planes z = 0, y = x, and y = 0.
    Show Solution

    Step 1: Set up the bounds.

    First octant means x, y, z ≥ 0.
    z bounds: 0 ≤ z ≤ 2 - x²
    y bounds: bounded by y = 0 and y = x, so 0 ≤ y ≤ x
    x bounds: To stay in the first octant with z ≥ 0, 2 - x² ≥ 0 meaning x² ≤ 2, so x ≤ √2.

    Integral: ∫ [0 to √2] ∫ [0 to x] ∫ [0 to 2-x²] xyz dz dy dx

    Step 2: Evaluate inner integral (dz).

    ∫ [0 to 2-x²] xyz dz = xy[z²/2] from 0 to 2-x² = (1/2)xy(2 - x²)²

    Expand: (1/2)xy(4 - 4x² + xˆ4) = 2xy - 2x³y + (1/2)xˆ5y

    Step 3: Evaluate middle integral (dy).

    ∫ [0 to x] (2xy - 2x³y + (1/2)xˆ5y) dy = [xy² - x³y² + (1/4)xˆ5y²] from 0 to x

    Substitute y = x:

    = x(x²) - x³(x²) + (1/4)xˆ5(x²) = x³ - xˆ5 + (1/4)xˆ7

    Step 4: Evaluate outer integral (dx).

    ∫ [0 to √2] (x³ - xˆ5 + (1/4)xˆ7) dx = [xˆ4/4 - xˆ6/6 + xˆ8/32] from 0 to √2

    Substitute x = √2 (so x² = 2, xˆ4 = 4, xˆ6 = 8, xˆ8 = 16):

    = (4/4) - (8/6) + (16/32) = 1 - 4/3 + 1/2

    Find common denominator (6): 6/6 - 8/6 + 3/6 = 1/6

    Answer: 1/6

  6. Problem 48: Evaluate the triple integral:

    ∫∫∫_G cos(z/y) dV

    where G is the solid defined by the inequalities π/6 ≤ y ≤ π/2, y ≤ x ≤ π/2, and 0 ≤ z ≤ xy.
    Show Solution

    Step 1: Set up the integral based on given inequalities.

    ∫ [π/6 to π/2] ∫ [y to π/2] ∫ [0 to xy] cos(z/y) dz dx dy

    Step 2: Evaluate inner integral (dz).

    ∫ [0 to xy] cos(z/y) dz = [y sin(z/y)] from 0 to xy

    = y sin(xy/y) - y sin(0) = y sin(x)

    Step 3: Evaluate middle integral (dx).

    ∫ [y to π/2] y sin(x) dx = [-y cos(x)] from y to π/2

    = -y cos(π/2) - (-y cos(y)) = 0 + y cos(y) = y cos(y)

    Step 4: Evaluate outer integral (dy).

    ∫ [π/6 to π/2] y cos(y) dy

    Use integration by parts: Let u = y, dv = cos(y) dy.
    Then du = dy, v = sin(y).

    ∫ u dv = uv - ∫ v du = [y sin(y)] - ∫ sin(y) dy = [y sin(y) + cos(y)]

    Evaluate from π/6 to π/2:

    Upper bound: (π/2)sin(π/2) + cos(π/2) = π/2(1) + 0 = π/2

    Lower bound: (π/6)sin(π/6) + cos(π/6) = (π/6)(1/2) + √3/2 = π/12 + √3/2

    Subtract lower from upper: π/2 - (π/12 + √3/2) = 6π/12 - π/12 - √3/2 = 5π/12 - √3/2

    Answer: 5π/12 - √3/2
