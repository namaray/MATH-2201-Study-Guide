Chapter 11.5: Parametric Equations of Lines

  1. Problem 1: Find parametric equations of the line that passes through the point (2, -1, 5) and is parallel to the vector v = <-1, 2, 7>.
    Show Solution

    Step 1: Identify the given point and direction vector.

    Point: (x₀, y₀, z₀) = (2, -1, 5)

    Direction Vector: v = <a, b, c> = <-1, 2, 7>

    Step 2: Plug into the parametric formulas.

    The standard formulas are: x = x₀ + at, y = y₀ + bt, z = z₀ + ct.

    Answer:

    x = 2 - t

    y = -1 + 2t

    z = 5 + 7t

  2. Problem 2: Show that the lines L₁ and L₂ intersect, and find their point of intersection.

    L₁: x = 2 + t, y = 2 + 3t, z = 3 + t
    L₂: x = 2 + s, y = 3 + 4s, z = 4 + 2s
    (Note: We use parameter 's' for L₂ to avoid confusion with 't' from L₁)
    Show Solution

    Step 1: Set the x, y, and z equations equal to each other.

    For an intersection to exist, there must be a specific t and s where the coordinates match.

    1) 2 + t = 2 + s &implies; t = s

    2) 2 + 3t = 3 + 4s

    3) 3 + t = 4 + 2s

    Step 2: Solve the system of equations.

    Substitute t = s (from eq 1) into eq 2:

    2 + 3t = 3 + 4t

    -1 = t

    Since t = s, we also have s = -1.

    Step 3: Check if these values satisfy the third equation (z).

    Plug t = -1 into L₁'s z-equation: z = 3 + (-1) = 2

    Plug s = -1 into L₂'s z-equation: z = 4 + 2(-1) = 4 - 2 = 2

    Since the z-values match, the lines do intersect.

    Step 4: Find the point of intersection.

    Plug t = -1 into L₁'s equations (or s = -1 into L₂'s):

    x = 2 + (-1) = 1
    y = 2 + 3(-1) = -1
    z = 2

    Answer: The point of intersection is (1, -1, 2).

Chapter 11.6: Planes in 3-Space

  1. Problem 3: Find an equation of the plane that passes through the point P(2, 6, 1) and has the vector n = <1, 4, 2> as a normal.
    Show Solution

    Step 1: Use the point-normal form of a plane.

    a(x - x₀) + b(y - y₀) + c(z - z₀) = 0

    Here, (x₀, y₀, z₀) = (2, 6, 1) and <a, b, c> = <1, 4, 2>.

    Step 2: Substitute the values and expand.

    1(x - 2) + 4(y - 6) + 2(z - 1) = 0

    x - 2 + 4y - 24 + 2z - 2 = 0

    x + 4y + 2z - 28 = 0

    Answer: x + 4y + 2z = 28

  2. Problem 4: Find an equation of the plane that passes through the given points: A(-2, 1, 1), B(0, 2, 3), and C(1, 0, -1).
    Show Solution

    Step 1: Find two vectors that lie in the plane.

    AB = <0 - (-2), 2 - 1, 3 - 1> = <2, 1, 2>

    AC = <1 - (-2), 0 - 1, -1 - 1> = <3, -1, -2>

    Step 2: Find the normal vector n by taking the cross product of AB and AC.

    n = AB × AC = | i j k |
    | 2 1 2 |
    | 3 -1 -2 |

    n = i((1)(-2) - (2)(-1)) - j((2)(-2) - (2)(3)) + k((2)(-1) - (1)(3))

    n = i(-2 + 2) - j(-4 - 6) + k(-2 - 3)

    n = <0, 10, -5>

    Step 3: Use the normal vector and one of the points to write the equation.

    Using point B(0, 2, 3) and n = <0, 10, -5>:

    0(x - 0) + 10(y - 2) - 5(z - 3) = 0

    10y - 20 - 5z + 15 = 0

    10y - 5z = 5

    Divide by 5 to simplify:

    Answer: 2y - z = 1
