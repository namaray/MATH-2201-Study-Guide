Chapter 11.5

  1. Problem 16: Find parametric equations of the line that satisfies the stated conditions.
    (a) The line through (-5, 2) that is parallel to 2i - 3j.
    (b) The line through (0, 3) that is parallel to the line x = -5 + t, y = 1 - 2t.
    (c) The line through (-1, 2, 4) that is parallel to 3i - 4j + k.
    (d) The line through (2, -1, 5) that is parallel to <-1, 2, 7>.
    (e) The line through (-2, 0, 5) that is parallel to the line x = 1 + 2t, y = 4 - t, z = 6 + 2t.
    (f) The line through the origin that is parallel to the line x = t, y = -1 + t, z = 2.
    Show Solution

    The parametric equations of a line through (x₀, y₀, z₀) parallel to vector v = <a, b, c> are x = x₀ + at, y = y₀ + bt, z = z₀ + ct.

    (a) Point (-5, 2), Direction vector <2, -3> (This is in 2-space).
    Answer: x = -5 + 2t, y = 2 - 3t

    (b) Point (0, 3). The parallel line has direction vector <1, -2>.
    Answer: x = t, y = 3 - 2t

    (c) Point (-1, 2, 4), Direction vector <3, -4, 1>.
    Answer: x = -1 + 3t, y = 2 - 4t, z = 4 + t

    (d) Point (2, -1, 5), Direction vector <-1, 2, 7>.
    Answer: x = 2 - t, y = -1 + 2t, z = 5 + 7t

    (e) Point (-2, 0, 5). The parallel line has direction vector <2, -1, 2>.
    Answer: x = -2 + 2t, y = -t, z = 5 + 2t

    (f) Point (0, 0, 0). The parallel line has direction vector <1, 1, 0> (since z=2 is constant, c=0).
    Answer: x = t, y = t, z = 0

  2. Problem 17: Where does the line x = 1 + 3t, y = 2 - t intersect
    (a) the x-axis
    (b) the y-axis
    Show Solution

    (a) Intersecting the x-axis:

    On the x-axis, y = 0. Set the y-equation to 0:

    2 - t = 0 &implies; t = 2

    Substitute t = 2 into the x-equation:

    x = 1 + 3(2) = 1 + 6 = 7

    Answer (a): The point is (7, 0).

    (b) Intersecting the y-axis:

    On the y-axis, x = 0. Set the x-equation to 0:

    1 + 3t = 0 &implies; t = -1/3

    Substitute t = -1/3 into the y-equation:

    y = 2 - (-1/3) = 2 + 1/3 = 7/3

    Answer (b): The point is (0, 7/3).

  3. Problem 18: Find the intersections of each of the following lines with the xy-plane, the xz-plane, and the yz-plane.
    Line 1: x = -2, y = 4 + 2t, z = -3 + t
    Line 2: x = -1 + 2t, y = 3 + t, z = 4 - t
    Show Solution

    Line 1: x = -2, y = 4 + 2t, z = -3 + t

    • xy-plane (z = 0): -3 + t = 0 &implies; t = 3.
      Plug in t=3: x = -2, y = 4 + 2(3) = 10, z = 0. Point: (-2, 10, 0)
    • xz-plane (y = 0): 4 + 2t = 0 &implies; t = -2.
      Plug in t=-2: x = -2, y = 0, z = -3 + (-2) = -5. Point: (-2, 0, -5)
    • yz-plane (x = 0): The line equation states x = -2 constantly. It can never be 0. Therefore, it does not intersect the yz-plane.

    Line 2: x = -1 + 2t, y = 3 + t, z = 4 - t

    • xy-plane (z = 0): 4 - t = 0 &implies; t = 4.
      Plug in t=4: x = -1 + 8 = 7, y = 3 + 4 = 7, z = 0. Point: (7, 7, 0)
    • xz-plane (y = 0): 3 + t = 0 &implies; t = -3.
      Plug in t=-3: x = -1 + 2(-3) = -7, y = 0, z = 4 - (-3) = 7. Point: (-7, 0, 7)
    • yz-plane (x = 0): -1 + 2t = 0 &implies; t = 1/2.
      Plug in t=1/2: x = 0, y = 3 + 1/2 = 7/2, z = 4 - 1/2 = 7/2. Point: (0, 7/2, 7/2)
  4. Problem 19: Show that the lines L₁ and L₂ intersect, and find their point of intersection.
    (a) L₁: x = 2 + t, y = 2 + 3t, z = 3 + t
         L₂: x = 2 + t, y = 3 + 4t, z = 4 + 2t

    (b) L₁: x + 1 = 4t, y - 3 = t, z - 1 = 0
         L₂: x + 13 = 12t, y - 1 = 6t, z - 2 = 3t
    Show Solution

    Important: When finding intersections of two lines, always change the parameter variable of the second line (e.g., to 's') to avoid treating them as the same variable.

    Part (a):

    L₁: x = 2 + t, y = 2 + 3t, z = 3 + t
    L₂: x = 2 + s, y = 3 + 4s, z = 4 + 2s

    Set equations equal:
    1) 2 + t = 2 + s &implies; t = s
    2) 2 + 3t = 3 + 4s

    Substitute t = s into (2): 2 + 3s = 3 + 4s &implies; s = -1. Thus, t = -1.

    Check the z-equation:
    L₁ z: 3 + (-1) = 2
    L₂ z: 4 + 2(-1) = 2.
    Since 2 = 2, the lines intersect.

    Plug t = -1 into L₁ to find the point: (2 - 1, 2 - 3, 3 - 1).

    Answer (a): The point of intersection is (1, -1, 2).

    Part (b):

    First, rewrite the lines explicitly in parametric form:
    L₁: x = -1 + 4t, y = 3 + t, z = 1
    L₂: x = -13 + 12s, y = 1 + 6s, z = 2 + 3s

    Set equations equal:
    Because L₁ has a constant z = 1, L₂'s z-value must also be 1.
    2 + 3s = 1 &implies; 3s = -1 &implies; s = -1/3

    Plug s = -1/3 into L₂ to find the candidate intersection point:
    x = -13 + 12(-1/3) = -13 - 4 = -17
    y = 1 + 6(-1/3) = 1 - 2 = -1
    Point candidate: (-17, -1, 1)

    Now verify if a t exists for L₁ to reach this point:
    -1 + 4t = -17 &implies; 4t = -16 &implies; t = -4
    Check y: y = 3 + (-4) = -1. It matches perfectly!

    Answer (b): The point of intersection is (-17, -1, 1).

  5. Problem 20: Show that the lines L₁ and L₂ are skew.
    (a) L₁: x = 1 + 7t, y = 3 + t, z = 5 - 3t
         L₂: x = 4 - t, y = 6, z = 7 + 2t

    (b) L₁: x = 2 + 8t, y = 6 - 8t, z = 10t
         L₂: x = 3 + 8t, y = 5 - 3t, z = 6 + t
    Show Solution

    Two lines are skew if they are not parallel and do not intersect.

    Part (a):

    Direction vectors are v₁ = <7, 1, -3> and v₂ = <-1, 0, 2>. They are not scalar multiples, so they are not parallel.

    Check for intersection (use 's' for L₂):
    L₁: x = 1 + 7t, y = 3 + t, z = 5 - 3t
    L₂: x = 4 - s, y = 6, z = 7 + 2s

    Equate y: 3 + t = 6 &implies; t = 3.
    Equate x with t=3: 1 + 7(3) = 4 - s &implies; 22 = 4 - s &implies; s = -18.
    Check z with these values:
    L₁ z: 5 - 3(3) = -4
    L₂ z: 7 + 2(-18) = -29
    Since -4 ≠ -29, they do not intersect. Therefore, the lines are skew.

    Part (b):

    Direction vectors are v₁ = <8, -8, 10> and v₂ = <8, -3, 1>. They are not scalar multiples, so they are not parallel.

    Check for intersection (use 's' for L₂):
    L₁: x = 2 + 8t, y = 6 - 8t, z = 10t
    L₂: x = 3 + 8s, y = 5 - 3s, z = 6 + s

    Equate x: 2 + 8t = 3 + 8s &implies; 8t - 8s = 1
    Equate y: 6 - 8t = 5 - 3s &implies; -8t + 3s = -1
    Add these two equations together:
    (8t - 8s) + (-8t + 3s) = 1 - 1
    -5s = 0 &implies; s = 0

    If s = 0, then 8t - 0 = 1 &implies; t = 1/8.
    Check z with these values:
    L₁ z: 10(1/8) = 5/4
    L₂ z: 6 + 0 = 6
    Since 5/4 ≠ 6, they do not intersect. Therefore, the lines are skew.

  6. Problem 21: Determine whether the lines L₁ and L₂ are parallel.
    (a) L₁: x = 3 - 2t, y = 4 + t, z = 6 - t
         L₂: x = 5 - 4t, y = -2 + 2t, z = 7 - 2t

    (b) L₁: x = 5 + 3t, y = 4 - 2t, z = -2 + 3t
         L₂: x = -1 + 9t, y = 5 - 6t, z = 3 + 8t
    Show Solution

    Two lines are parallel if their direction vectors are scalar multiples of each other.

    Part (a):

    Direction vector for L₁: v₁ = <-2, 1, -1>

    Direction vector for L₂: v₂ = <-4, 2, -2>

    Check ratios: -4 / -2 = 2, 2 / 1 = 2, -2 / -1 = 2.

    Since v₂ = 2v₁, the direction vectors are parallel.

    Answer (a): Yes, the lines are parallel.

    Part (b):

    Direction vector for L₁: v₁ = <3, -2, 3>

    Direction vector for L₂: v₂ = <9, -6, 8>

    Check ratios: 9 / 3 = 3, -6 / -2 = 3, but 8 / 3 ≠ 3.

    Since the ratios are not equal, one vector is not a scalar multiple of the other.

    Answer (b): No, the lines are not parallel.

Chapter 11.6: Planes in 3-Space

  1. Problem 22: Find an equation of the plane that passes through the point P and has the vector n as a normal.
    (a) P(2, 6, 1), n = <1, 4, 2>
    (b) P(-1, -1, 2), n = <-1, 7, 6>
    (c) P(1, 0, 0), n = <0, 0, 1>
    Show Solution

    Use the point-normal form of a plane: a(x - x₀) + b(y - y₀) + c(z - z₀) = 0

    (a) P(2, 6, 1), n = <1, 4, 2>

    1(x - 2) + 4(y - 6) + 2(z - 1) = 0

    x - 2 + 4y - 24 + 2z - 2 = 0

    Answer (a): x + 4y + 2z = 28

    (b) P(-1, -1, 2), n = <-1, 7, 6>

    -1(x - (-1)) + 7(y - (-1)) + 6(z - 2) = 0

    -1(x + 1) + 7(y + 1) + 6(z - 2) = 0

    -x - 1 + 7y + 7 + 6z - 12 = 0

    Answer (b): -x + 7y + 6z = 6 (or x - 7y - 6z = -6)

    (c) P(1, 0, 0), n = <0, 0, 1>

    0(x - 1) + 0(y - 0) + 1(z - 0) = 0

    Answer (c): z = 0 (This is the xy-plane).

  2. Problem 23: Find the distance between the point and the plane.
    (a) (1, -2, 3); 2x - 2y + z = 4
    (b) (0, 1, 5); 3x + 6y - 2z - 5 = 0
    Show Solution

    Use the distance formula: D = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²)

    (a) Point (1, -2, 3), Plane 2x - 2y + z - 4 = 0 (Note: move 4 to the left side).

    D = |2(1) - 2(-2) + 1(3) - 4| / √(2² + (-2)² + 1²)

    D = |2 + 4 + 3 - 4| / √(4 + 4 + 1)

    D = |5| / √9 = 5 / 3

    Answer (a): 5/3

    (b) Point (0, 1, 5), Plane 3x + 6y - 2z - 5 = 0.

    D = |3(0) + 6(1) - 2(5) - 5| / √(3² + 6² + (-2)²)

    D = |0 + 6 - 10 - 5| / √(9 + 36 + 4)

    D = |-9| / √49 = 9 / 7

    Answer (b): 9/7

  3. Problem 24: Find the distance between the given parallel planes.
    (a) -2x + y + z = 0,       6x - 3y - 3z - 5 = 0
    (b) x + y + z = 1,       x + y + z = -1
    Show Solution

    To find the distance between parallel planes, pick an arbitrary point on one plane and use the point-to-plane distance formula to the second plane.

    (a) Planes: -2x + y + z = 0 and 6x - 3y - 3z - 5 = 0

    Find a point on the first plane. Let x = 0, y = 0, then z = 0. Point: (0, 0, 0).

    Calculate distance from (0, 0, 0) to 6x - 3y - 3z - 5 = 0:

    D = |6(0) - 3(0) - 3(0) - 5| / √(6² + (-3)² + (-3)²)

    D = |-5| / √(36 + 9 + 9) = 5 / √54 = 5 / (3√6)

    Answer (a): 5 / (3√6)

    (b) Planes: x + y + z - 1 = 0 and x + y + z + 1 = 0

    Find a point on the first plane. Let y = 0, z = 0, then x = 1. Point: (1, 0, 0).

    Calculate distance from (1, 0, 0) to x + y + z + 1 = 0:

    D = |1(1) + 1(0) + 1(0) + 1| / √(1² + 1² + 1²)

    D = |2| / √3 = 2 / √3

    Answer (b): 2 / √3

  4. Problem 25: Find the distance between the given skew lines.
    (a) L₁: x = 1 + 7t, y = 3 + t, z = 5 - 3t
         L₂: x = 4 - t, y = 6, z = 7 + 2t

    (b) L₁: x = 3 - t, y = 4 + 4t, z = 1 + 2t
         L₂: x = t, y = 3 - t, z = 2t
    Show Solution

    To find the distance between skew lines, find a plane that contains L₂ and is parallel to L₁. The distance from any point on L₁ to this plane is the distance between the skew lines.

    (a)
    Direction vectors: v₁ = <7, 1, -3> and v₂ = <-1, 0, 2>.
    Point on L₁ (let t=0): P₁(1, 3, 5).
    Point on L₂ (let t=0): P₂(4, 6, 7).

    Find normal vector n for the plane containing L₂ parallel to L₁: n = v₁ × v₂
    n = <7, 1, -3> × <-1, 0, 2> = <(1)(2)-(0)(-3), -((7)(2)-(-1)(-3)), (7)(0)-(-1)(1)>
    n = <2, -(14 - 3), 1> = <2, -11, 1>

    Equation of plane containing L₂: use P₂(4, 6, 7) and n=<2, -11, 1>.
    2(x - 4) - 11(y - 6) + 1(z - 7) = 0
    2x - 8 - 11y + 66 + z - 7 = 0 &implies; 2x - 11y + z + 51 = 0

    Find distance from P₁(1, 3, 5) to this plane:
    D = |2(1) - 11(3) + 1(5) + 51| / √(2² + (-11)² + 1²)
    D = |2 - 33 + 5 + 51| / √(4 + 121 + 1) = |25| / √126

    Answer (a): 25 / √126

    (b)
    Direction vectors: v₁ = <-1, 4, 2> and v₂ = <1, -1, 2>.
    Point on L₁ (let t=0): P₁(3, 4, 1).
    Point on L₂ (let t=0): P₂(0, 3, 0).

    Find normal vector n: n = v₁ × v₂
    n = <-1, 4, 2> × <1, -1, 2> = <(4)(2)-(-1)(2), -((-1)(2)-(1)(2)), (-1)(-1)-(1)(4)>
    n = <8 + 2, -(-2 - 2), 1 - 4> = <10, 4, -3>

    Equation of plane containing L₂: use P₂(0, 3, 0) and n=<10, 4, -3>.
    10(x - 0) + 4(y - 3) - 3(z - 0) = 0
    10x + 4y - 12 - 3z = 0 &implies; 10x + 4y - 3z - 12 = 0

    Find distance from P₁(3, 4, 1) to this plane:
    D = |10(3) + 4(4) - 3(1) - 12| / √(10² + 4² + (-3)²)
    D = |30 + 16 - 3 - 12| / √(100 + 16 + 9) = |31| / √125

    Answer (b): 31 / √125

  5. Problem 26: Find an equation of the plane that passes through the given points.
    (a) (-2, 1, 1), (0, 2, 3), (1, 0, -1)
    (b) (3, 2, 1), (2, 1, -1), (-1, 3, 2)
    Show Solution

    Find two vectors in the plane, cross them to find the normal vector n, then use point-normal form.

    (a) Let A(-2,1,1), B(0,2,3), C(1,0,-1).
    AB = <0 - (-2), 2 - 1, 3 - 1> = <2, 1, 2>
    AC = <1 - (-2), 0 - 1, -1 - 1> = <3, -1, -2>

    n = AB × AC = |i j k|
    |2 1 2|
    |3 -1 -2|
    n = <(1)(-2)-(2)(-1), -((2)(-2)-(3)(2)), (2)(-1)-(3)(1)>
    n = <-2 + 2, -(-4 - 6), -2 - 3> = <0, 10, -5>

    Use point B(0,2,3):
    0(x - 0) + 10(y - 2) - 5(z - 3) = 0
    10y - 20 - 5z + 15 = 0
    10y - 5z = 5 (Divide by 5)

    Answer (a): 2y - z = 1

    (b) Let A(3,2,1), B(2,1,-1), C(-1,3,2).
    AB = <2-3, 1-2, -1-1> = <-1, -1, -2>
    AC = <-1-3, 3-2, 2-1> = <-4, 1, 1>

    n = AB × AC = | i j k|
    |-1 -1 -2|
    |-4 1 1|
    n = <(-1)(1)-(-2)(1), -((-1)(1)-(-2)(-4)), (-1)(1)-(-1)(-4)>
    n = <-1 + 2, -(-1 - 8), -1 - 4> = <1, 9, -5>

    Use point A(3,2,1):
    1(x - 3) + 9(y - 2) - 5(z - 1) = 0
    x - 3 + 9y - 18 - 5z + 5 = 0
    x + 9y - 5z - 16 = 0

    Answer (b): x + 9y - 5z = 16

  6. Problem 27: Determine whether the planes are parallel, perpendicular, or neither.
    (a) 2x - 8y - 6z - 2 = 0,       -x + 4y + 3z - 5 = 0
    (b) x - y + 3z - 2 = 0,       2x + z = 1
    (c) 3x - 2y + z = 4,       6x - 4y + 3z = 7
    Show Solution

    Examine the normal vectors of the planes. If they are scalar multiples, the planes are parallel. If their dot product is 0, they are perpendicular.

    (a) n₁ = <2, -8, -6>, n₂ = <-1, 4, 3>
    Notice that n₁ = -2(n₂). They are scalar multiples.
    Answer (a): Parallel.

    (b) n₁ = <1, -1, 3>, n₂ = <2, 0, 1>
    They are not scalar multiples.
    Dot product: n₁ · n₂ = (1)(2) + (-1)(0) + (3)(1) = 2 + 0 + 3 = 5.
    Since the dot product is not 0, they are not perpendicular.
    Answer (b): Neither.

    (c) n₁ = <3, -2, 1>, n₂ = <6, -4, 3>
    Check ratios: 6/3=2, -4/-2=2, but 3/1 ≠ 2. Not parallel.
    Dot product: n₁ · n₂ = (3)(6) + (-2)(-4) + (1)(3) = 18 + 8 + 3 = 29.
    Since the dot product is not 0, they are not perpendicular.
    Answer (c): Neither.

  7. Problem 28: Determine whether the line and plane are parallel, perpendicular, or neither.
    (a) Line: x = 4 + 2t, y = -t, z = -1 - 4t
         Plane: 3x + 2y + z - 7 = 0

    (b) Line: x = 1, y = 2t, z = 3t
         Plane: x - y + 2z = 5

    (c) Line: x = -1 + 2t, y = 4 + t, z = 1 - r
         Plane: 4x + 2y - 2z = 7
    Show Solution

    Compare the line's direction vector (v) to the plane's normal vector (n).
    - If v and n are parallel (scalar multiples), the line is perpendicular to the plane.
    - If v and n are perpendicular (dot product = 0), the line is parallel to the plane.

    (a) v = <2, -1, -4>, n = <3, 2, 1>
    Not scalar multiples (not perpendicular).
    Dot product: v · n = (2)(3) + (-1)(2) + (-4)(1) = 6 - 2 - 4 = 0.
    Because v is perpendicular to n, the line runs along the plane.
    Answer (a): Parallel.

    (b) v = <0, 2, 3>, n = <1, -1, 2>
    Not scalar multiples (not perpendicular).
    Dot product: v · n = (0)(1) + (2)(-1) + (3)(2) = 0 - 2 + 6 = 4.
    Not zero (not parallel).
    Answer (b): Neither.

    (c) v = <2, 1, -1> (assuming r is the parameter, so z = 1 - 1r), n = <4, 2, -2>
    Notice that n = 2(v). They are scalar multiples.
    Because v is parallel to n, the line shoots straight through the plane.
    Answer (c): Perpendicular.

  9. Problem 30: Determine whether the line and plane intersect; if so, find the coordinates of the intersection.
    (a) Line: x = t, y = t, z = t
         Plane: 3x - 2y + z - 5 = 0

    (b) Line: x = 2 - t, y = 3 + t, z = t
         Plane: 2x + y + z = 1

    (c) Line: x = 3t, y = 5t, z = -t
         Plane: 2x - y + z + 1 = 0
    Show Solution

    (a) Substitute into 3x - 2y + z - 5 = 0:
    3(t) - 2(t) + (t) - 5 = 0
    2t = 5 &implies; t = 5/2
    Point: (5/2, 5/2, 5/2).
    Answer (a): They intersect at (5/2, 5/2, 5/2).

    (b) Substitute into 2x + y + z = 1:
    2(2 - t) + (3 + t) + (t) = 1
    4 - 2t + 3 + 2t = 1
    7 = 1
    This is a contradiction.
    Answer (b): They are parallel and do not intersect.

    (c) Substitute into 2x - y + z + 1 = 0:
    2(3t) - (5t) + (-t) + 1 = 0
    6t - 5t - t + 1 = 0
    0 + 1 = 0 &implies; 1 = 0
    This is a contradiction.
    Answer (c): They are parallel and do not intersect.

  10. Problem 31: Find the acute angle of intersection of the planes to the nearest degree.
    (a) x = 0,       2x - y + z - 4 = 0
    (b) x + 2y - 2z = 5,       6x - 3y + 2z = 8
    Show Solution

    The angle between two planes is the angle between their normal vectors: cos(θ) = |n₁ · n₂| / (||n₁|| ||n₂||)

    (a) n₁ = <1, 0, 0>, n₂ = <2, -1, 1>
    n₁ · n₂ = (1)(2) + 0 + 0 = 2
    ||n₁|| = 1
    ||n₂|| = √(2² + (-1)² + 1²) = √6
    cos(θ) = |2| / (1 * √6) = 2/√6
