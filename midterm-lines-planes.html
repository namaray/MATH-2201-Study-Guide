Lines and Planes in 3-Space (Chapters 11.5 - 11.6)

In 2D geometry, lines are defined by slopes and y-intercepts. In 3-space, we use vectors to define both lines (using parallel direction vectors) and planes (using perpendicular normal vectors).

Chapter 11.5: Parametric Equations of Lines

Key Concepts

  • A line in 3-space is determined uniquely by a point on the line and a non-zero vector parallel to the line.
  • Skew Lines: Two lines in 3-space that are not parallel and do not intersect are called skew lines. (This is a concept unique to 3D space).
  • Line Segments: A line segment is just a line restricted to a specific domain of the parameter t (usually 0 ≤ t ≤ 1).

Core Formulas

Parametric Equations of a Line:
If a line passes through point P₀(x₀, y₀, z₀) and is parallel to vector v = <a, b, c>, the equations are:
x = x₀ + at
y = y₀ + bt
z = z₀ + ct
(where t is any real number from -∞ to +∞)
Vector Equation of a Line:
Using vector notation, if r₀ = <x₀, y₀, z₀> is the position vector of the point, and r = <x, y, z> is the position vector of any point on the line:
r = r₀ + tv
Symmetric Equations:
By solving the parametric equations for t and setting them equal, we get (if a, b, c are non-zero):
(x - x₀)/a = (y - y₀)/b = (z - z₀)/c

Chapter 11.6: Planes in 3-Space

Key Concepts

  • A plane in 3-space is uniquely determined by a point in the plane and a vector perpendicular to the plane, called a normal vector (n).
  • Parallel Planes: Two planes are parallel if and only if their normal vectors are scalar multiples of each other.
  • Intersecting Planes: Two non-parallel planes intersect in a straight line. The direction vector of this line of intersection is the cross product of the two planes' normal vectors (v = n₁ × n₂).
  • Angle between Planes: The acute angle of intersection between two planes is the angle between their normal vectors.

Core Formulas

Point-Normal Equation of a Plane:
If a plane passes through P₀(x₀, y₀, z₀) and has normal vector n = <a, b, c>:
Vector form: n · (r - r₀) = 0
Component form: a(x - x₀) + b(y - y₀) + c(z - z₀) = 0
General Form of a Plane:
By expanding the point-normal equation, we get:
ax + by + cz + d = 0
(Notice that you can read the normal vector directly from the coefficients of x, y, and z: n = <a, b, c>)
Distance Between a Point and a Plane:
The shortest distance D from a point P₀(x₀, y₀, z₀) to the plane ax + by + cz + d = 0 is:
D = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²)
Pro-Tip for Finding Planes: If you are given three points P, Q, and R on a plane and need to find the equation, first create two vectors (e.g., PQ and PR). Then, find the normal vector by taking their cross product: n = PQ × PR. Finally, use n and any one of the points in the point-normal formula.
